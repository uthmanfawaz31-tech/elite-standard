# Elite Standard Web Application

Live static web application for **Elite Standard**.

## Features
- **Landing / Login Page**: `index.html` with interactive particle animation.
- **Dashboard**: `dashboard.html` showcasing Elite Standard apps with downloader codes and direct download links.
- **Responsive Design**: Designed for desktop, tablet, and mobile screens.

## Quick Start
Run locally using Node.js:
```bash
node server.js
```
Then open `http://localhost:3000/` in your browser.
